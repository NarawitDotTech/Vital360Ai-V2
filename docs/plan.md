# Vitals 360 AI: build plan (this run)

Full brief: `docs/brief/prompt.md` (original spec) and `docs/brief/plan-original.md` (team plan, incl. elderly-friendly UX rules). This file records what this run builds and the decisions that differ.

## Scope of this run (agreed with the team)
- **App only** (Phase 1 + the app-side parts of Phase 4): Next.js static PWA, Thai-first i18n, consent, 3 capture flows, results with disclaimers, history, delete-my-data, evaluation dashboard reading `eval/metrics/*.json` (sample file, clearly marked as mock data).
- Inference: **mock models** behind the shared contract (`src/inference/types.ts`). Respiration rate is real signal processing (no training needed). Fusion = logistic regression from a JSON weights file (placeholder weights until trained).
- Supabase: **migrations only** (schema, RLS, delete-account Edge Function), app fully usable without it.
- Out of scope this run: dataset report, GPU playbook, training notebooks, real ONNX models.

## Decisions
| Area | Choice |
|---|---|
| Framework | Next.js 16.4.3 App Router, `output: "export"`, `trailingSlash: true`, TS 5.9.3, Tailwind 4.3.3. **Next 16 differs from older versions: read `node_modules/next/dist/docs/` before using an API.** |
| Locales | Routes `/th/...` (default) and `/en/...` via `src/app/[locale]/` + `generateStaticParams`. Root `/` redirects client-side to `/th/`. Typed dictionaries `src/i18n/{th,en}.ts`, no i18n library. |
| Inference | `onnxruntime-web` 1.31.1 in one Web Worker, lazy-loaded only when a manifest entry has a real `url`. Mock backend is deterministic. |
| Vision ROI | `@mediapipe/tasks-vision` 1.2.0, lazy-loaded; fallback = fixed chest box from the framing guide. |
| Storage | IndexedDB (hand-written tiny wrapper, no dependency): history, consent record. |
| PWA | Hand-written `public/sw.js` + `public/manifest.webmanifest`. |
| Brand | `assets/icon.svg` (team-supplied). Teal `#23c2c6` for accents/icon only; text uses dark teal `#0b6e72` (passes AA on white). Icons generated by `npm run icons` (sharp). |
| Tests | Vitest 5 (jsdom, fake-indexeddb) for logic; Playwright 1.64.1 smoke (uses pre-installed Chromium). |
| Hosting | Cloudflare Pages (static, `public/_headers` for CSP/HSTS). |

## Ownership (parallel agents, disjoint paths)
- **frontend**: `src/app/**`, `src/components/**`, `src/i18n/**`, `src/storage/**`, `src/capture/**`, `public/` (except `public/models/`, `public/_headers`), `scripts/icons.mjs`, `e2e/**`, `playwright.config.ts`, `eval/metrics/`.
- **inference**: `src/inference/**` (keep `types.ts` contract backward compatible), `public/models/**`.
- **backend**: `supabase/**`, `public/_headers`, `.github/workflows/**`, `.env.example`, `lighthouserc.json`.
- Shared files (`package.json`, `next.config.ts`, `vitest.config.ts`, `tsconfig.json`): orchestrator only. Agents ask in their final report if they need a change.

## Definition of done for this run
`npm run lint && npm run typecheck && npm test && npm run build` pass; Playwright smoke passes (consent -> capture with fake media -> result shows disclaimer); static export works offline after first load; th/en key parity test passes; reviewer pass done.
