# ai agent: decisions and open questions (2026-10-30)

Scope this run: research and training scaffolding only. Nothing was trained; **notebooks have never been executed** (no GPU, no torch in this sandbox). Only `py_compile` plus `pyflakes` (undefined-name check) passed on all extracted cells and helpers.

## Files
- `docs/data-report.md`: ranked datasets, mapping tables, fairness plan, fusion problem.
- `docs/gpu-training-playbook.md`: free/cheap GPU options with verified prices, step by step, I/O contract.
- `training/kaggle/skin.ipynb`, `audio.ipynb`: generated by `training/kaggle/build_notebooks.py` from `nb_src/*.py` and `common/*.py` (edit those, then `python3 training/kaggle/build_notebooks.py --check`).
- `training/kaggle/common/`: seed, ckpt, calib (temperature, ECE, coverage), metrics (dashboard JSON, subgroup report), train (resumable AMP loop), export (ONNX, int8 QDQ, fp16, parity, manifest patch), mel (torch front end identical to `mel.ts`, fixture writer).

## Decisions
1. Kaggle is the primary platform; everything else is backup. No paid GPU recommended.
2. Skin: MobileNetV3-Large (torchvision IMAGENET1K_V2) default, EfficientNet-Lite0 via timm optional. 3 tiers. HAM10000 required, PAD-UFES-20 (phone) strongly recommended. Group-level split, 80/10/10, seed 42. DermNet excluded (AI use prohibited by its terms). DDI/SCIN kept as external fairness test sets, local only.
3. Audio: 4 classes exactly as the manifest. ICBHI cycles (both-class dropped) + COUGHVID expert-labelled. No audio class is red.
4. Model contract follows `ort.ts` exactly (ImageNet-normalised NCHW 224 squash; `[1,1,501,64]` raw log-mel). The audio model normalises inside the graph (per-clip mean removal + fixed std) so no change in the app is needed and gain does not matter.
5. Calibration is done on validation only; temperature and abstain threshold go to the manifest, not into the ONNX graph.
6. Artifact choice is gated: int8 only if top-1 agreement >= 0.97 and macro-F1 drop <= 0.02 on the test split; else fp16/fp32. Everything must be <= 15 MB.
7. Dashboard metrics are produced from the file that ships (the ONNX), on the held-out split; extra detail goes to a separate `report_*.json` so the dashboard schema is untouched. `latencyMs` is Kaggle CPU, must be re-measured on a phone.

## Open questions / risks (ranked)
1. **Domain gap** (biggest): skin = mostly dermoscopy; audio wheeze/crackle = stethoscope only. Reported accuracy will be optimistic for phone use. Mitigated only by PAD-UFES-20, phone-like augmentation and per-source reporting. A small team-collected phone set (with consent and clinician labels) is the real fix.
2. **Fusion cannot be validated** with public data (data-report section 7). The dashboard must not present a simulated multimodal gain as measured. Team decision needed: pilot study with a partner clinic or declare the hypothesis untested.
3. **App-side resize mismatch**: `ort.ts` samples nearest-neighbour from the full-resolution photo (aliasing). Ask the inference agent to pre-scale with a smoothing canvas before `getImageData`. Also the app squashes (no crop); training matches that.
4. **Mel parity TS vs Python is unverified**: fixture `mel_fixture.json` is produced by the audio notebook; the inference agent needs to add the vitest. The resamplers differ (box average vs soxr).
5. Notebooks never executed: library API drift (torch ONNX exporter, torchvision v2, onnxruntime quantization) is likely to need small fixes; COUGHVID and PAD-UFES-20 column names are asserted at runtime but not verified.
6. ORT-web with int8 QDQ and the WebGPU provider is untested; the session falls back to wasm if creation fails, but speed is unknown.
7. Licences: HAM10000 and ISIC (2019/2020/2024 NC) are CC BY-NC; weights derived from them are fine for a school project, grey for a public service. DermNet forbidden. ICBHI licence text not found. SCIN licence has a no-re-identification clause.
8. Thai skin-tone coverage: none of the datasets contain Thai patients; fairness section commits to reporting per Fitzpatrick group and flagging gaps.
9. Time-outs: Kaggle quota/session facts came from search snippets (docs page did not render); confirm in your account.
